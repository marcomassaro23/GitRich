# 📌 GitRich
**GitRich** è un RPG gestionale a turni in cui il giocatore guida una startup software al successo, bilanciando decisioni strategiche e risorse aziendali per evitarne il fallimento.

---
## 🚀 Come eseguire il progetto
### Prerequisiti
- Java 25 (LTS)
- Gradle
### Istruzioni
```bash
git clone https://github.com/marcomassaro23/GitRich.git
cd GitRich
```
### Build del progetto
```bash
./gradlew build
```
### Esecuzione
```bash
./gradlew run
```
---
## 🤖 Uso di strumenti di AI

Durante lo sviluppo di **GitRich**, **Gemini** è stato utilizzato esclusivamente come strumento di supporto mirato, affiancando la progettazione e l'implementazione svolte in autonomia:

- **Debugging e configurazione:** supporto nella risoluzione di errori di compilazione, anomalie legate a JavaFX e configurazione dell'ambiente Gradle.
- **Generazione dei contenuti:** stesura e strutturazione del file XML contenente gli eventi di gioco e le relative opzioni di scelta.
- **Documentazione:** supporto lessicale e revisione dei testi del repository.

Tutti i suggerimenti proposti sono stati analizzati, compresi e adattati manualmente prima dell'integrazione nel progetto.
